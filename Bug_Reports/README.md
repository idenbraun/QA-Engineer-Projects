# 🐞 Bug Reports

Примеры баг-репортов, оформленных в процессе тестирования веб- и мобильных приложений.

## 📋 Что внутри

Каждый репорт содержит:
- Уникальный ID
- Заголовок (краткая суть проблемы)
- Серьёзность и приоритет
- Окружение (ОС, браузер, версия приложения)
- Шаги для воспроизведения
- Фактический и ожидаемый результат
- Скриншоты / видео с доказательствами
- Дополнительные заметки

## 🛠️ Инструменты

Для оформления использовались:
- Google Sheets
- Инструменты для скриншотов: Adobe Express Photos
- Charles Proxy / DevTools — для багов, связанных с сетью

## 📌 Пример

Один из типичных кейсов — баг с валидацией формы при вводе граничных значений (см. `bug-001.md`).
