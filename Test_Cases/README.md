# 📝 Test Cases

Детализированные тест-кейсы для функционального тестирования модулей приложений.

## 📋 Структура кейса

Каждый тест-кейс включает:
- ID и заголовок
- Предусловия
- Тестовые данные
- Шаги с ожидаемыми результатами
- Приоритет (High/Medium/Low)
- Статус выполнения
- Привязку к требованию (опционально)

## 🎯 Что покрыто

- Позитивные и негативные сценарии
- Граничные значения и классы эквивалентности
- Переходы состояний
- Интеграционные проверки (UI + Backend)

## 🛠️ Инструменты

- Тест-кейсы написаны в Google Sheets
- Экспортированы в Markdown для демонстрации в портфолио

## 📂 Разделы

- `auth-module` — регистрация, логин, восстановление пароля
- `search-filter` — поиск и фильтрация товаров
- `order-flow` — создание и отслеживание заказа

---

> *Все кейсы протестированы на реальных тестовых средах в рамках учебных проектов.*
