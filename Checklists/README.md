# ✅ Checklists

Чек-листы для smoke-тестирования, регресса и приёмочного тестирования ключевых модулей.

## 📋 Что внутри

Чек-листы покрывают:
- Функциональность (позитивные и негативные проверки)
- UI/UX (отображение на разных разрешениях, состояния элементов)
- Интеграции с API (статус-коды, структура ответов)
- Кроссбраузерность

Каждый чек-лист представлен в виде списка кратких проверок без детальных шагов — для быстрых прогонов.

## 🛠️ Инструменты

- Составлены в формате Markdown / Google Sheets
- Адаптированы под конкретную фичу и сборку

## 📂 Структура

- `auth-checklists` — проверки авторизации и регистрации
- `cart-payment` — корзина и оплата
- `api-smoke` — быстрая проверка основных эндпоинтов

---

> *Используются как основа для тестовых прогонов в учебных проектах.*
