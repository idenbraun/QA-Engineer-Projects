## Автоматизация (первые шаги)

**Стек:** Java 11+, Maven, JUnit 5

Юнит-тесты для сервиса расчёта бонусов — это один из первых учебных проектов в рамках изучения Java.  
Покрыл основные сценарии: зарегистрированный/незарегистрированный пользователь, сумма выше и ниже лимита.  

📂 [Посмотреть папку с автотестами](https://github.com/idenbraun/QA-Engineer-Projects/tree/main/autotests)

**Что внутри:**
- `pom.xml` — зависимости: JUnit 5
- `BonusServiceTest.java` — 4 тест-кейса с проверкой граничных условий
- Тесты запускаются командой `mvn test`
